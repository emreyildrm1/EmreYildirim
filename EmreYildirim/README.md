# 🌐 HeroMessage Vue Component

Bu proje, kişisel portfolyo sayfam için geliştirdiğim Vue.js tabanlı bir ana bileşeni (hero section) içerir. Şık bir cam efekti (glassmorphism) ile modern bir arayüz sunar. Projede ismim, unvanım ve iletişim bilgilerim görsel olarak öne çıkarılmıştır.

## ✨ Özellikler

- Cam efekti (Glassmorphism) tasarımı
- Responsive (mobil, tablet, masaüstü) uyumluluk
- Vue 3 Composition API kullanımı
- Sass/SCSS ile özelleştirilebilir stil yapısı
- Google Fonts & özel ikonlar
- GitHub, LinkedIn ve mail bağlantıları

## 🛠️ Kullanılan Teknolojiler

- [Vue 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/) (isteğe bağlı build aracı)
- [Sass/SCSS](https://sass-lang.com/)
- [Google Fonts](https://fonts.google.com/)
- HTML5 & CSS3
